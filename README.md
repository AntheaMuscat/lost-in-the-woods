# 🌲 Lost in the Woods

### *The forest remembers. The forest changes. Will you find your way out?*

## 📖 About the Game

**Lost in the Woods** is a fictional mystery-adventure survival game where players explore a mysterious forest that changes every night.

After waking up alone in an unfamiliar forest, players must explore their surroundings, solve puzzles, collect resources and uncover hidden secrets to find their way home.

However, the forest is not what it seems. Paths disappear, strange creatures watch from the shadows, and every decision can change the outcome of the adventure.

## 🎮 Game Genre

- Mystery
- Adventure
- Survival
- Puzzle
- Light Horror

## ✨ Key Features

- 🌳 **Changing Forest:** Explore an environment that changes every night.
- 🔍 **Hidden Mysteries:** Discover secret messages, symbols and forgotten objects.
- 🔦 **Survival Mechanics:** Manage resources, collect supplies and find shelter.
- 👁️ **Mysterious Creatures:** Avoid strange creatures hiding in the forest.
- 🧩 **Environmental Puzzles:** Solve puzzles to unlock new locations.
- 🌙 **Multiple Endings:** Your decisions influence how the story ends.

## 🎯 Target Audience

Players aged 16–30 who enjoy mystery, exploration, survival and atmospheric adventure games.

## 🌐 Project Overview

This project involves developing a single-page promotional website for our fictional game, **Lost in the Woods**.

The website will introduce the game, showcase its storyline and features, display visual assets and encourage visitors to wishlist the game.

## 🚀 Getting Started

To access the project locally:

```bash
git clone [repository-url]
cd lost-in-the-woods
```

Install dependencies (once the Vite project has been created):

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
